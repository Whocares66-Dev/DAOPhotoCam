# Controls

| Key | Does |
|---|---|
| <kbd>F8</kbd> | Photo Cam on and off |
| <kbd>Esc</kbd> | Off |
| <kbd>F7</kbd> | Lock the view: the keys and mouse no longer move it |
| Right mouse button, held | Look around (the pointer hides) |
| <kbd>W</kbd> / <kbd>S</kbd> | Forward / back, the way the view looks |
| <kbd>A</kbd> / <kbd>D</kbd> | Left / right |
| <kbd>Q</kbd> / <kbd>E</kbd> | Straight up / down |
| Wheel | Faster / slower, 0.5 to 40 m/s |
| <kbd>Shift</kbd> + wheel | Narrower / wider field of view, 15° to 120° |

Each start begins at 4 m/s and the game's own field of view.

## Rebinding

Every key but the mouse and the wheel is in **Options → Controls**, under **Photo Cam**.

<kbd>Esc</kbd>, <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> and <kbd>Q</kbd> <kbd>E</kbd> are Photo Cam's only while it is on. The rest of the time they do what the game has them do.

## While it is on

- The world is paused, the party and every fight with it, and the game's interface is hidden.
- It ends by itself if the game opens a menu, a conversation or a load. The camera goes back to the party.
