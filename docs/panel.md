# UI panel

While Photo Cam is on, a panel stands in the screen's bottom right, made of the game's own controls.

![The UI panel]({{ "/assets/img/panel.png" | relative_url }}){: .ui width="400" loading="lazy"}

| | |
|---|---|
| **Lock camera** | As <kbd>F7</kbd>: the view holds still |
| **Field of view** | Drag, or click the arrows for 5° a step |
| **Move speed** | Drag, or click the arrows |
| **Capture** | Takes the game's own screenshot |
| **Exit** | Photo Cam off |
| **–** | Shrinks the panel to its title; **+** brings it back |

The panel follows the keys: turn the wheel and its slider moves. It is never in a screenshot, whether taken with **Capture** or the game's screenshot key.

![Photo Cam on, the panel in the corner]({{ "/assets/img/photo-cam-on.jpg" | relative_url }}){: .screenshot loading="lazy"}

## The top bar

A camera button stands in the game's top bar, before Options. Click it to turn Photo Cam on. Its tooltip names the key bound to it.

![The top bar, the camera button before Options]({{ "/assets/img/top-bar.png" | relative_url }}){: .ui width="420" loading="lazy"}
